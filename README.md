# NOAHFI web (Next.js 15, TypeScript, Tailwind)

    npm install
    npm run dev      # http://localhost:3000
    npm run build

Routes: `/`, `/login`, `/signup`, `/partner/login`, `/internal/login`, `/architecture`.

Notes
- The hero score translator is an illustration (linear mapping). Replace or remove before launch.
- Bank names in the consent card and the ledger/API samples are placeholders.
- FAQ and security copy should be reviewed by compliance before publishing.
- Auth forms are UI shells; wire them to your auth backend.
